0. O mapa mental

Separe quatro coisas: base da máquina, interfaces de desenvolvimento, agentes/CLI/TUI e acesso econômico (assinatura, API, router).

Base

Git · Node · Python

Runtimes e ferramentas que muitos CLI/TUI usam.

Ambiente

Windows · WSL · VPS

PATH, filesystem, shell e permissões não são iguais.

Superfície

App · IDE · CLI/TUI

A mesma capacidade pode aparecer em interfaces diferentes.

1. Windows zerado

Microsoft oficial

WSL 2 + Ubuntu

Guia oficial WSL

wsl --install
wsl --list --verbose

O primeiro comando pode exigir reboot. Para aula ao vivo, use snapshot pós-reboot.

Base recomendada

Git, Node LTS, Python, VS Code, Chrome

  • Git
  • Node.js — use LTS
  • Python
  • Visual Studio Code
  • Google Chrome
winget install --id Git.Git -e --source winget
winget install --id Microsoft.VisualStudioCode -e
Node: para a base geral, prefira a versão LTS mostrada na página oficial. Não fixe “Current” só porque é a maior versão. Ferramentas específicas podem exigir outra faixa.

2. WSL / Ubuntu / VPS

O mesmo bootstrap funciona muito bem em WSL e numa VPS Ubuntu/Debian.

Bootstrap
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl unzip jq ripgrep build-essential ca-certificates python3 python3-pip python3-venv

Node LTS via nvm:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
. "$HOME/.nvm/nvm.sh"
nvm install 24
node -v && npm -v && python3 --version && git --version

A versão do nvm/Node muda. O link oficial do Node acima deve ser a fonte de verdade perto da aula.

7. Smoke test

□ wsl --list --verbose funciona
□ git --version funciona
□ node -v && npm -v funciona
□ python3 --version / Python funciona
□ VS Code abre projeto no ambiente escolhido
□ pelo menos 1 agente/CLI/TUI abre e autentica
□ diferença entre app, IDE, CLI/TUI e API está clara
□ API key pode ser criada e armazenada sem expor segredo
